# Tutorial 2

Date: 31/7/26

## Q1 — Student (`Q1_Student.java`)

A college wants to store the details of a student, including the student's name, roll number, and department. The system should display the student's information.

**Task:** Create a class `Student`. Create an object. Display the student's details.

## Q2 — Book (`Q2_Book.java`)

A library wants to keep track of books. Each book has a title, author, and price. When a new book is added, its details should be displayed.

**Task:** Create a class `Book`. Store the title, author, and price. Display the book details.

## Q3 — Student Registration (`Q3_StudentRegistration.java`)

A college is developing a Student Registration System to store basic information about newly admitted students. For every student, the system should store the student's name and roll number. The college also wants a feature to display the student's details whenever required.

**Task:** Create a class `Student`. Store the student's name and roll number. Create a method `display()` to print the student's details.

## Q4 — Rectangle (`Q4_Rectangle.java`)

An interior designer wants to estimate the floor area of a rectangular room before placing furniture. The application should store the length and breadth of the room and calculate its area.

**Task:** Create a class `Rectangle`. Store the length and breadth. Create a method to calculate and display the area of the rectangle.

## Q5 — Multiple Students (`Q5_MultipleStudents.java`)

A school wants to maintain records of multiple students. The system should be able to store and display the details of different students individually.

**Task:** Create a class `Student`. Create two student objects with different names and ages. Display the details of both students.

## Q6 — Employee (`Q6_Employee.java`)

A company is building an Employee Management System to maintain employee records. Each employee has their own information, and the system should display the details of multiple employees.

**Task:** Create a class `Employee`. Create two employee objects with different information. Display the details of both employees.

## Q7 — Marks (`Q7_Marks.java`)

After the semester examinations, a college wants to automatically calculate each student's total marks and average marks based on marks obtained in three subjects.

**Task:** Create a class `Marks`. Store the marks of three subjects. Calculate and display the total marks and average marks.

## Q8 — Temperature (`Q8_Temperature.java`)

A weather monitoring station records the temperature in Celsius, but an international weather report requires the temperature in Fahrenheit. The system should perform the conversion automatically.

**Task:** Create a class `Temperature`. Store the temperature in Celsius. Convert it to Fahrenheit using the formula `F = C * 9/5 + 32`. Display both the Celsius and Fahrenheit temperatures.
