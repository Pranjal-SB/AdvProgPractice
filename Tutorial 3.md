## Q1 — Supermarket Bill (`Q1_SupermarketBill.java`)

A supermarket wants to calculate the total bill for a customer. (NOTE: Implement using `if` statement, `for` loop, Array)

**Task:**
- Read the prices of five products.
- Store them in an array.
- Calculate the total bill.
- If the total bill exceeds ₹5000, display "Discount Applicable"; otherwise display "No Discount".

**Sample Input:**
```
1200
1500
800
1000
900
```

**Expected Output:**
```
Total Bill : 5400
Discount Applicable
```

## Q2 — Attendance (`Q2_Attendance.java`)

A school records attendance for seven days. (NOTE: Implement using `if` statement, `for` loop, Array)

**Task:**
- Store attendance values (1 for Present, 0 for Absent) in an array.
- Count the total number of present days.
- If attendance is greater than or equal to 75%, print "Eligible for Exam"; otherwise print "Not Eligible".

## Q3 — Employee Constructor (`Q3_EmployeeConstructor.java`)

A company wants to store employee details using object-oriented programming.

**Task:**
- Create an `Employee` class.
- Use a constructor to initialize Employee ID, Employee Name, and Salary.
- Display all employee details.

**Sample Input:**
```
Employee ID : 101
Employee Name : Rahul
Salary : 45000
```

**Expected Output:**
```
Employee ID : 101
Employee Name : Rahul
Salary : 45000
```

**Task:** Write a Java program using constructor overloading to support all three registration methods and display the car details.
